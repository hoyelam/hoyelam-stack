# Codex delegation

Tool schemas and session instructions govern models, context limits, and worker capacity. Keep those values out of portable guidance.

## Context

Use the [delegation brief](single-task-delegation.md#shape-the-work). Choose a self-contained brief, recent-history fork, or full history based on the assignment and supported tools. Balance handoff size against missing context and repeated discovery. Follow runtime rules for model inheritance and overrides.

Keep large logs in task-owned files; return conclusions, useful excerpts, and artifact paths. Load skills and references that help the assignment.

## Control

Reuse idle workers when their role and context fit. Send corrections or interrupt work that is wrong, unsafe, or no longer useful. Prefer completion notifications or bounded waits over polling. Keep useful lead work moving and inspect results before accepting them; tool completion alone does not prove correctness.
